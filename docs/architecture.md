# 架构与验证契约

```text
CCXT 公共数据 → 原始快照 → 质量检查 → Polars 清洗/特征 → Parquet
                                      ↘ 可选 TimescaleDB 查询缓存
Parquet → 因子批处理 → 训练期 IC/IR + 多重校正 → 滚动样本外 → 最终 holdout 报告

模拟行情/组合状态 → 实时风控 → NautilusPaperRouter → NautilusTrader 模拟引擎
```

研究与执行只共享不可变领域值。`data`、`alpha`、`research` 不能导入 `execution`；执行模块不能依赖研究模块。配置由严格模型解析，未知字段报错；密钥不出现在 YAML。Python 3.13 和锁定的 `uv` 依赖保证本地环境隔离与可重复安装。

## 数据决策

- 所有时间边界为 UTC；请求使用半开区间 `[start, end)`。分页上限导致截断时抛错。
- CCXT 每个交易所复用一个实例，使其内置限速器持续生效。订单簿是当前快照。
- 原始响应追加归档；Parquet 对同键修订只保留最后观测，TimescaleDB 可从归档重建。
- 缺失值默认保留为空。显式前值填充会标记 `is_imputed`，不能把填充值当成交。
- 复权因子由外部显式提供，要求 `known_at <= timestamp`；不自动推断公司行为。
- Timescale hypertable 的唯一键包含其分区时间。数据库不可用时离线测试仍运行。

## 统计决策

- 内置因子只用已完成的过去 K 线。未来收益标签不跨越训练/测试边界。
- 每次运行先封存最终 holdout；滚动窗口带与收益期限相符的 embargo。
- 使用时间序列区块 bootstrap 做训练期筛选，再按预声明候选集合校正 p 值。
- IC/IR 是横截面诊断，不等于可交易收益。vectorbt 扫描只允许可表达的成本模型。
- 最终报告列出所有尝试、数据哈希、配置哈希、成本、窗口和未解决风险。

## 执行决策与剩余风险

- NautilusTrader 仅作本地模拟；2.0.0rc6 是预发布版本，不用于实盘。
- 原生引擎持有订单状态机，路由只做提交前风控和状态观测。
- 限价单一律按新增风险敞口处理；卖单也不会自动被视为减仓。
- 模拟配置默认拒绝未校准参数。滑点模型基于一跳 tick 概率，不能替代市场冲击估计。
- 当前没有实盘账户、历史 L2/L3 深度、资金费率执行结算、对账、长时间模拟盘服务或极端情境数据。任何绩效结论均需另行验证这些环节。
